# Repair Proof schema v1.0
Fields: proof_schema_version, proof_id, run_id, repo_id, base_sha, tested_base_tree, patch_hash, changed_files, path_scope, claim, warrant{warrant_id,status,scope,expires_at,test_only}, warrant_is_demo, tools, commands_executed[{label,command,status,exit_code,started,ended,duration_s,summary,reason,evidence_ref}], static_checks, static_findings, patch_breaker{status,findings,checks}, auditor, residual_risk, limitations, evidence[{ref,kind,sha256}], overall_status, reason, next_action, proof_hash, attestation.
Hash: SHA-256 of canonical JSON (sorted keys, no whitespace, ASCII) of the proof excluding `proof_hash`, `attestation`, `evidence_content`. Export (`/v1/runs/{id}/proof`) adds `evidence_content`, each entry verifiable against `evidence[].sha256`.
Attestation: `none` = hash-linked integrity proof, NOT a digital signature. If `IRA_PROOF_HMAC_KEY` is set: `hmac-sha256` over proof_hash (shared secret; no non-repudiation). Public-key signing is not implemented (no stdlib support); key management is therefore just keeping the env var secret.
