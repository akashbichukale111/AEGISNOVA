# Architecture
`ira/core.py` pipeline: RECEIVED → IDENTITY_VALIDATION (parse/limits/paths/apply to declared base) → STATIC_ANALYSIS → TEST_PLAN → TEST_EXECUTION (warrant-gated, before+after on temp copies) → INDEPENDENT_AUDIT (Patch Breaker rules R1-R8 + Reality Auditor) → WARRANT_CHECK → RESIDUAL_RISK → PROOF_GENERATION. Terminal: VERIFIED, VERIFIED_WITH_WARNINGS, REJECTED, FAILED, BLOCKED, NEEDS_HUMAN_REVIEW (FAILED is reserved for internal errors; none currently emitted).
`ira/warranty.py` Living Repair Warranty (JSON files in `.data/warranties`, snapshot of repaired tree in `.data/snapshots`). `ira/server.py` HTTP API + `ui/index.html`. `ira/cli.py` CLI. Persistence: JSON files under `.data/runs`. Responsibilities are separate: breaker challenges, auditor compares claims to executed evidence, runner executes allowlisted commands, warrant checker handles authority only, proof records, risk reports unknowns, warranty tracks staleness. Governance (UNWIND) is out of scope.
