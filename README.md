## 🌟 Executive Overview & Hackathon Submission

AEGISNOVA is an end-to-end autonomous software engineering and governed operations platform. Unlike conventional coding assistants that propose unverified snippets or evaluate their own outputs, AEGISNOVA guarantees that every change is:
1. **Discovered via Real AST & Manifest Intelligence (Mode A):** Full repository map, language composition, entry points, test runners, and dependency vulnerability hypotheses with exact file paths and line numbers.
2. **Turned into Autonomous Tasks in One Click:** Direct bridge from diagnostic finding to repair loop.
3. **Executed through a 12-Stage Verifiable Pipeline (Mode B):** Bounded edits powered by NVIDIA NIM (`Nemotron-4-340B`, `Llama-3.1-405B`).
4. **Proven via Deterministic Test Execution:** Discovers and executes local unit test suites (`python -m unittest`, `npm test`), capturing exit codes, durations, stdout, and stderr.
5. **Audited by DevGuard AI:** Deep static vulnerability and hardcoded secret scanning.
6. **Independently Verified (Adversarial Verifier):** Separate evaluator in a fresh context specifically designed to prevent LLM self-verification bias.
7. **Authorized by UNWIND Governance Core:** Warrant ledger debits (`-150 bp`) and immutable decision lineage hashes.
8. **Sealed into a Proof-Carrying Pull Request (PCPR):** SHA-256 evidence package containing all telemetry, test outputs, and security receipts.

## 💡 Real Innovation: Why AEGISNOVA is Not Just Another AI Wrapper

Most "AI coding assistants" are simple chat prompts that return disconnected snippets in markdown. They leave testing, compiling, security scanning, and Git operations entirely to the human engineer.

**AEGISNOVA is fundamentally different because it introduces a closed-loop Governed Execution Fabric:**

1. **Closed-Loop Test Harness (Never Blindly Trust LLMs):** AEGISNOVA never marks a task complete until real test commands (`unittest`, `pytest`, `npm test`) actually execute in an isolated environment with `exitCode: 0`.
2. **The 3:00 AM Dual Autonomy Policy:** It solves the on-call fatigue dilemma. Routine Low/Medium tasks self-resolve autonomously without waking developers, while High/Critical issues (CVEs, SQL injections, data leaks) are quarantined for 1-Click human countersignature.
3. **Self-Healing Recurrent Memory Ledger:** Every resolved incident signature is cryptographically recorded. If the same error pattern recurs across subsequent runs or days, the agents auto-heal it instantly in 0 ms from memory.
4. **Proof-Carrying Pull Requests (PCPR):** Pull requests contain cryptographic receipts (SHA-256 evidence manifest, AST blast-radius analysis, and DevGuard security receipts).
5. **UNWIND Governance & Decaying Warrant Ledger:** High-consequence actions are bounded by tenant warrant leases, preventing runaway agent loops and guaranteeing complete lineage auditability.

## 🤖 NightShift 3 AM Patrol: Dual Autonomy Policy & Copilot Terminal

AEGISNOVA introduces the **Dual Autonomy Policy** for on-call engineers, preventing unnecessary 3:00 AM wakeups while enforcing cryptographic human governance for critical changes:

```
+-------------------------------------------------------------------------------------------------+
|                               NIGHTSHIFT 3 AM AUTONOMOUS PATROL                                 |
+-------------------------------------------------------------------------------------------------+
                                                |
                              [ AST & Security Severity Classifier ]
                                                |
                 +------------------------------+------------------------------+
                 |                                                             |
                 v                                                             v
    [ LOW / MEDIUM SEVERITY ]                                     [ HIGH / CRITICAL SEVERITY ]
  - Linter errors, typing drift,                                - SQL injection, hardcoded secrets,
    deprecated syntax, doc regressions                            RCE vectors, auth bypass
                 |                                                             |
                 v                                                             v
  [ Zero-Wakeup Autonomous Fix ]                                [ Quarantined: WAITING_APPROVAL ]
  - Synthesize bounded patch                                    - Formulate candidate patch
  - Run deterministic test sandbox                              - Run Tavily live CVE verification
  - Commit to Recurrent Memory Ledger                           - Prepare UNWIND warrant debit (-150 bp)
                 |                                                             |
                 v                                                             v
  [ Next Occurrence: Instant Auto-Heal ]                        [ 1-Click SDE Countersignature ]
  - Solved in 0 ms with 0 human interruption                    - SDE approves via Web UI in 1 click
```

### Key Capabilities:
1. **Interactive GitHub URL Bar & Natural Language Prompting:** Paste any public or private GitHub repository (`https://github.com/org/repo`), select your target branch, and instruct agents in plain natural language.
2. **Zero-Touch Auto-Healing (No Wakeup):** Low and Medium issues are resolved autonomously without triggering pagers.
3. **Recurrent Incident Memory Ledger:** Solution patterns are stored in a self-learning ledger. If the same error signature recurs tomorrow night, agents recognize it and heal it immediately from memory.
4. **UNWIND 1-Click SDE Approval:** High and Critical issues hold execution until the on-call SDE clicks "1-Click SDE Approve", which validates the patch, debits the UNWIND warrant ledger (`-150 bp`), and commits the changes.

## ⚡ Quick Start Guide

### Prerequisites
- **Node.js**: v18+ (tested on Node v24.18.0)
- **Python**: 3.10+ (tested on Python 3.13)
- **Git**: Installed and configured

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/akashbichukale111/AEGISNOVA.git
cd AEGISNOVA

# Install frontend dependencies
npm install

# (Optional) Setup environment variables
cp .env.example .env
```

### 2. Run Automated Verification Suite
```bash
npm test
```
*Executes 116+ automated smoke checks verifying contracts, API routes, security boundaries, and token hygiene with 0 failures.*

### 3. Start Backend Services (Multi-Process Local Mode)

#### Terminal 1 — Autonomous Operations Backend
```bash
cd services/autonomous-operations
python -m aegisnova_ops
```
*Listens on `http://127.0.0.1:8080` (SQLite queue, state machine, webhook proxy).*

#### Terminal 2 — NightShift SDE Daemon
```bash
cd services/nightshift-sde
python -m nightshift serve
```
*Listens on `http://127.0.0.1:8787` (local workspace worker daemon).*

#### Terminal 3 — AEGISNOVA Web Application
```bash
npm run build
npm start
```
*Open **[http://localhost:3000](http://localhost:3000)** in your browser.*

## 🔒 Security Posture & Threat Model

1. **Tokens Never Leave the Server:** `GITHUB_TOKEN`, `NVIDIA_API_KEY`, and `NEBIUS_API_KEY` are read exclusively on the server side (`process.env`). They are never exposed in client responses, HTML source, browser storage, or exported manifests.
2. **Honest Authentication Boundaries:** If `GITHUB_TOKEN` is unconfigured, the UI explicitly displays `READ-ONLY PUBLIC / LOCAL DEMO`. No synthetic fake PR links or fabricated delivery states are generated.
3. **No Self-Verification:** The autonomous coding agent cannot verify its own code. An Independent Adversarial Verifier evaluates diffs in a separate context for regressions, prompt injection, and unauthorized writes.
4. **UNWIND Governance Authority:** High-consequence code changes require explicit warrant authorization (`-150 bp`) and human countersignature.
